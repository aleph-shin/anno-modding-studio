# Proposals

Each larger feature of the Studio was planned in a proposal before it was
built: what it is for, what it was measured against, the choices weighed and
the order to build it in. They are listed in the order they were written (all
in 2026), and kept as written, so they say what was known then. Each opens
with a status line, read against the code on the date it gives, that says how
far it got and what has moved on since.

For how the Studio works now, read the [user guide](../guide.md), the
[design notes](../design-notes.md) and the [architecture](../architecture.md)
before any of these.

The proposals were written before the repository was made public. Where one names
`REVIEW.md`, a review pass, an audit run, or an issue or PR by its number, that is
the earlier private repository's record, which isn't published.
